# 煤气泡 (BubbleNotify)

一个 LSPosed 模块，把通知、音乐、来电变成屏幕角落的气泡。

## 功能

- **气泡通知**：所有通知以胶囊形式出现在屏幕角落，点开才展开卡片，绝不自动展开
- **三级形态**：展开卡片 / 小胶囊 / 贴边图标，逐级切换；新通知只弹自己的胶囊
- **音乐播放器**：胶囊显示歌名 - 歌手 + 旋转唱片，卡片显示歌词（取自通知）
- **来电接管**：来电只显示气泡卡，不弹系统横幅和全屏页；点卡片可打开系统通话页
- **验证码识别**：本地识别短信验证码 / 取件码，规则可自定义，不联网
- **钉住**：点气球钉住一条通知或播放器，钉住后不自动缩小、不自动贴边；其余通知照常缩小贴边
- **长按拖动**：长按贴边图标、胶囊或展开卡片，拖动改变 dock 位置，松手按左右半屏与上下半屏吸附
- **自定义**：胶囊 / 卡片的宽度、高度、透明度、圆角都能调，卡片底边位置可调，改完立即生效
- **左右滑**：左滑消除，右滑贴边；气泡在左边时左右镜像
- **自适应毛玻璃**：按壁纸亮暗自动切换深色 / 浅色毛玻璃

## 要求

- Root + LSPosed
- Android 8.0+（SDK 26+）
- 在魅族 Flyme 上小窗打开用 Flyme 的接口；其他系统气泡功能正常

## 安装

1. 安装 APK
2. 在 LSPosed 里启用「煤气泡」，作用域为 `com.android.systemui` 和 `com.android.incallui`
3. 重启手机
